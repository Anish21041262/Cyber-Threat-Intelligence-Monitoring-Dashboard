# Cyber-Threat-Intelligence-Monitoring-Dashboard
Developed a Threat Intelligence Monitoring Dashboard using Python and Streamlit to monitor and consolidate real-time cybersecurity news from multiple sources including The Hacker News, Dark Reading, Security News and BleepingComputer and other security platforms. The dashboard fetches and parses RSS feeds, categorizes news based on severity using keyword-based threat analysis, and provides interactive filtering, searching, and visualization features. Implemented dynamic charts and source-wise monitoring to improve threat visibility and situational awareness. Designed the platform to support cybersecurity analysts in tracking emerging threats, vulnerabilities, ransomware campaigns, phishing attacks, and global cyber incidents through a centralized interface.
